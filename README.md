### Basic Instructions


- run `npm install`
- create `.env` file
- setup properly all env variables
- run `npx prisma generate`
##### first time setup
- run `npx prisma migrate dev`

#### and then run `npm run dev`


### Important Notes

- `npm run dev` will run the server on `localhost:3000`
- `npm run build` will build the server
- `npm run start` will run the server

## Prisma Setup

- `npx prisma migrate dev`
- `npx prisma generate`
- `npx prisma db push`
- `npx prisma db seed`
- `npx prisma studio`
